## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Multi-Source** | Install addons from CurseForge, WoWInterface, GitHub, and Wago.io |
| **Auto Updates** | Keep all addons up to date automatically in the background |
| **Retail & Classic** | Full support for all WoW versions including Classic and Season of Discovery |
| **Open Source** | Community-run alternative to the official CurseForge client |
